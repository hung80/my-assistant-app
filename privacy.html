Privacy policy

Last updated: 13 November 2026

"My assistant" is a personal tool used only by its owner, on the owner's own Google account.

What it accesses

With the owner's consent through Google sign-in: the owner's Gmail messages, labels and drafts, and the owner's Google Calendar events (read only).

How the data is used

Only to show the owner what needs attention, file mail into the owner's own folders on request, and prepare draft replies the owner reviews. Nothing is sent automatically.

Where the data goes

Data is processed on the owner's own computer. It is not sold, shared, or transferred to anyone, and it is not used for advertising. Sign-in tokens are stored only on that computer.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke access at any time at myaccount.google.com/permissions.
